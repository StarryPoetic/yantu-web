# 知识库入口

招生事实与题库是两种独立发布的数据，不能混用版本或审核结论。

- [招生目录](catalog/README.md)：年度项目、来源、字段断言、科目、历史成绩、就业/政策证据与风险案例；有示例批次和扩建模板。
- [全国院校种子库](schools/README.md)：458所、31个省级行政区，含147所第二轮双一流。只提供官网和研究生招生网址线索，不证明招生专业、学费、校区或科目；维护与免费核验规则见 D-13。
- [诊断题库](questions/README.md)：题目修订、知识点、范围、难度、答案、解析和审校记录；答案只在服务端读取。
- [模型与网页问答](../server/explanation/README.md)：模型代码不放入知识库，检索到的网页也不自动成为已核验事实。

招生目录和题库文件是导入材料；正式可服务数据以数据库内经过审核的发布快照为准。编辑 JSON 不会静默覆盖正在使用的目录、题目或用户历史记录。院校种子在服务启动时加载为未经事实审核的发现线索。不要在任何知识库文件存储个人作答、密钥或账号凭据。

## 阶段4公共事实资料

`research_public_sources` 与 `research_program_facts` 属于独立公共院校资料库，读写接口统一由 `server/explanation/research-library.ts` 管理。ProgramFact 只由阶段2确定性绑定模块从公开原文生成；种子库只提供发现线索，模型回答、个人画像、查询文本和推荐结论不入事实表。

每条事实保留项目身份、字段、来源、连续原文、原获取时间与提取规则版本，始终 `verified:false`。全校统一学费继续保留 `school_wide` / `school_wide_mode`；城市级校区核验不升级成具体校区。`pending` 不用于预算或城市匹配，过期事实不能作为目标年度事实。

部署方运行 `scripts/prefetch-schools.mjs` 按城市、省份、学校和学科收集，遵守 robots.txt、每主机串行、间隔≥1秒，且不调用付费搜索或模型。资料负责人定期检查诊断与冲突，只有人工审核发布才能进入正式目录；运行责任见 D-14。
