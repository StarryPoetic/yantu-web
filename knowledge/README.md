# 知识库入口

招生事实与题库是两种独立发布的数据，不能混用版本或审核结论。

- [招生目录](catalog/README.md)：年度项目、来源、字段断言、科目、历史成绩、就业/政策证据与风险案例；有示例批次和扩建模板。
- [诊断题库](questions/README.md)：题目修订、知识点、范围、难度、答案、解析和审校记录；答案只在服务端读取。
- [模型与网页问答](../server/explanation/README.md)：模型代码不放入知识库，检索到的网页也不自动成为已核验事实。

数据文件是导入材料；正式可服务数据以数据库内经过审核的发布快照为准。编辑 JSON 不会静默覆盖正在使用的目录、题目或用户历史记录。不要在任何知识库文件存储个人作答、密钥或账号凭据。
