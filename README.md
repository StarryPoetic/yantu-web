# 研途 · 考研择校交互 Demo

根据 [产品设计文档](docs/产品设计文档.md) 实现的纯前端原型，用于评审视觉效果与交互流程。

## 本地启动

需要 Node.js 20.19+ 或 22.12+（本项目使用 Node.js 24 验证）。

```powershell
npm ci
npm run dev -- --port 4173
```

打开 http://127.0.0.1:4173 。生产构建使用 `npm run build`，预览构建使用 `npm run preview -- --port 4173`。

## 可以体验的流程

1. **择校探索**：6 个模拟项目、专业方向、搜索、城市 / 梯度 / 学位筛选、排序。
2. **个人画像**：背景、课程基础、备考进度、城市与跨专业偏好、7 项重要性设置；保存草稿、重置、删除资料。
3. **基础测评**：数学、英语、专业基础共 6 道示例题；切题、记录思路、跳过、提交、查看诊断与答案依据、重新测评。
4. **院校详情**：项目概览、3 年模拟分数、就业方向、评价依据状态、纠错草稿。
5. **收藏与对比**：收藏、排除与恢复、最多 3 个完整招生项目并排比较。
6. **目标与规划**：设置目标、查看分科目标与当前待评估状态、勾选阶段任务。
7. **择校报告**：预览并下载当前画像、收藏和目标的 Markdown 报告。
8. **数据管理**：招生资料、题库、评价证据的本地搜索、新增、编辑与复核演示。

支持桌面、平板与手机布局；弹窗支持 Escape 关闭和键盘焦点管理。

## 演示边界

- **没有后端、API、大模型、真实推荐算法、账户或支付服务。**筛选、排序、示例题评分、文件导出与状态切换在前端完成。
- 学校名称用于界面展示，项目组合、考试科目、分数、名额、分组、适配指标均为模拟，不构成报考建议。
- 调整画像会更新已保存资料及侧栏；推荐清单和理由使用固定示例，不根据个人输入进行真实评估。报考资格、目标年份的目录和单科线均待核验。
- 示例题只用于展示诊断过程，不能推断考研成绩或录取概率。历史门槛、备考目标、当前能力分别展示。
- 预置一份画像、一个收藏与一个目标，便于直接浏览；未预置已完成的测评。
- 个人资料、收藏、排除项、目标和任务存储在当前浏览器的 `localStorage`，键为 `yantu-demo-v1`。测评草稿使用 `yantu-demo-assessment-attempt`，后台记录使用 `yantu-demo-admin-records`，纠错草稿使用 `yantu-correction-<项目 ID>`。
- 删除资料会清除画像内容、测评结果和测评草稿；收藏与目标仍保留。清除该站点的浏览器存储可恢复全部初始演示状态。
- 使用本地图标与系统字体，页面运行不依赖外部图片、字体或接口。

## 验证

首次安装测试浏览器：

```powershell
npx playwright install chromium
```

运行全部检查：

```powershell
npm run build
npm test
npm run test:docs
```

Playwright 自动启动本地服务，每个测试使用独立浏览器上下文，覆盖筛选空态、收藏持久化、排除恢复、对比上限、详情键盘操作、目标与分数一致性、资料删除、测评、后台、报告下载及移动布局。截图和失败追踪输出到 `test-results/`，不提交到 Git。

## 主要文件

- `src/App.tsx`：页面框架、探索、收藏、对比、规划、报告与本地状态。
- `src/Flows.tsx`：画像、测评、管理页面。
- `src/SchoolDetail.tsx`：详情抽屉。
- `src/data.ts`：模拟招生项目。
- `src/types.ts`：页面与数据类型。
- `src/styles.css`、`src/flows.css`、`src/detail.css`：界面与响应式样式。
- `tests/demo.spec.ts`：端到端交互测试。
