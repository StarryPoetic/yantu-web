# 研途 · 考研择校交互 Demo

根据 [产品设计文档 V0.5](docs/产品设计文档.md) 整理的纯前端原型，用于评审视觉效果与交互流程。现有交互不代表 V0.5 的正式数据与推荐能力已经实现。

首版开发所需的设计文件及需求对应关系见 [技术设计文档清单](docs/技术设计/00-文档清单与需求映射.md)。这组文档是方案草案，尚未实施。

## 本地启动

需要 Node.js 20.19+ 或 22.12+（本项目使用 Node.js 24 验证）。

```powershell
npm ci
npm run dev -- --port 4173
```

打开 http://127.0.0.1:4173 。生产构建使用 `npm run build`，预览构建使用 `npm run preview -- --port 4173`。

## 可以体验的流程

1. **专业与院校联合探索**：首页展示 6 个模拟项目，提供计算机科学与技术、计算机技术两类方向与同校备选项目；从专业查看关联院校，也能从院校比较专业。支持搜索、城市 / 梯度 / 学位 / 专业方向筛选、排序、确认专业，以及学硕和专硕的点击说明。
2. **个人画像**：背景、课程基础、备考进度、跨专业偏好、7 项重要性设置；全国城市输入下拉多选，按拼音首字母 A–Z 分组，支持中文 / 拼音 / 首字母搜索、自定义城市和“不确定”；支持保存草稿、重置、删除资料。
3. **公共课测评**：数学、英语、政治各 5 道示例题，默认 15 题，模块可选且不强制数学。选中答案后短反馈并自动切到下一题，末题停留待主动提交；可返回修改、记录思路、跳过、查看诊断与答案依据、重新测评。
4. **可选专业测评**：确认目标专业后可以体验对应的 5 道专业基础题；不测专业课也可直接查看专业与院校推荐。本科专业资料不会自动视为已确认目标专业。
5. **院校详情**：项目概览、3 年模拟分数、就业方向、评价依据状态、纠错草稿。
6. **收藏与对比**：收藏、排除与恢复、最多 3 个完整招生项目并排比较。
7. **目标与规划**：设置目标、查看分科目标与当前待评估状态、勾选阶段任务。
8. **择校报告**：预览并下载当前画像、收藏和目标的 Markdown 报告。
9. **数据管理**：招生资料、题库、评价证据的本地搜索、新增、编辑与复核演示。

支持桌面、平板与手机布局。正文默认 16px，辅助说明至少 12px，表单与操作文字至少 14px；375px 手机布局自然换行，宽表格在自身容器内滚动。弹窗支持 Escape 关闭和键盘焦点管理。

## 演示边界

- **没有后端、API、大模型、真实推荐算法、账户或支付服务。**筛选、排序、示例题评分、文件导出与状态切换在前端完成。
- 学校名称用于界面展示，项目组合、考试科目、分数、名额、分组、适配指标均为模拟，不构成报考建议。
- 调整画像会更新已保存资料及侧栏；专业、院校与项目筛选会相互联动，但候选项目和说明仍为固定示例，不根据个人输入进行真实能力评估。报考资格、目标年份的目录和单科线均待核验。
- 示例题只用于展示诊断过程，不能推断考研成绩或录取概率。历史门槛、备考目标、当前能力分别展示。
- 预置一份画像、一个收藏与一个目标，便于直接浏览；未预置已完成的测评。
- 个人资料、收藏、排除项、目标和任务存储在当前浏览器的 `localStorage`，键为 `yantu-demo-v1`。新版测评草稿使用 `yantu-demo-assessment-attempt-v2` 并带版本信息，后台记录使用 `yantu-demo-admin-records`，纠错草稿使用 `yantu-correction-<项目 ID>`。
- 新版公共课与专业课测评按阶段和模块保存；旧版 6 题草稿与完成记录不作为新版结果使用，避免题号、答案和诊断串用。
- 城市目录是随页面打包的离线快照，并非实时或穷尽的行政区划名录；未覆盖的城市可自定义添加。具体来源、统计时间和覆盖范围见 [城市目录说明](docs/city-data.md)。选择某个城市不代表该城市已有演示院校。
- 删除资料会清除画像内容、测评结果和测评草稿；收藏与目标仍保留。清除该站点的浏览器存储可恢复全部初始演示状态。
- 使用本地图标与系统字体，页面运行不依赖外部图片、字体或接口。

## 验证

首次安装测试浏览器：

```powershell
npx playwright install chromium
```

运行全部检查：

```powershell
npm run build
npm test
npm run test:docs
```

Playwright 自动启动本地服务，每个测试使用独立浏览器上下文，覆盖筛选空态、专业与院校双向联动、学硕 / 专硕说明、城市中文与拼音搜索和多选保存、收藏持久化、排除恢复、对比上限、详情键盘操作、目标与分数一致性、资料删除、测评模块 / 自动切题 / 主动提交 / 旧缓存隔离、后台、报告下载、关键字号及 375px 移动布局。截图和失败追踪输出到 `test-results/`，不提交到 Git。

## 主要文件

- `src/App.tsx`：页面框架、探索、收藏、对比、规划、报告与本地状态。
- `src/Flows.tsx`：画像与管理页面。
- `src/CityPicker.tsx`、`src/cities.ts`：全国城市搜索、多选、自定义输入与离线目录。
- `src/AssessmentView.tsx`、`src/assessmentQuestions.ts`：分模块测评流程与本地示例题库。
- `src/MajorDiscovery.tsx`、`src/programs.ts`：专业发现、学位说明和关联项目示例。
- `src/SchoolDetail.tsx`：详情抽屉。
- `src/data.ts`：模拟招生项目。
- `src/types.ts`：页面与数据类型。
- `src/styles.css`、`src/flows.css`、`src/detail.css`：界面与响应式样式。
- `src/assessment.css`、`src/city-picker.css`：测评与城市选择器的补充样式。
- `tests/demo.spec.ts`：端到端交互测试。
