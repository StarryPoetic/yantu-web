# 可靠成绩与规划差距

本功能只提供成绩提交、独立审核、撤回和规划计算的流程。实际成绩来源与真实性由具备 `reviewer` 权限的独立人员核验，自动化测试使用内存或临时数据库中的合成材料，不构成真实成绩或人工审核记录。

学生在“目标与规划”选择已核验项目及官方科目后，可以提交实际考试或同口径模拟考试成绩、日期、来源及证明定位。项目年度、修订、考试组、科目和满分从当前目录核对；缺失时不能提交。自报估分和五题小测不进入当前分数。证明定位只保存内部核验所需信息，不上传原件，不自动访问链接，勿填密码、身份证号等无关信息。

成绩初始为待审核；审核者不能是提交人，必须逐项确认来源证明、可比范围、分数与日期，并填写说明。通过后，学生重新保存计划，服务端读取已审核的同口径成绩计算非负差距。成绩不能跨招生年度、项目修订、考试组、科目或满分借用，最新适用测量优先。

有效期暂按测量日起 **180 天**执行，这是保守的操作默认值，不是科学校准结论。日期只接受目标招生年度或前一年，且不得在未来。正式使用前，学科负责人仍需确认适合各科目的有效期与测量条件；未完成确认不意味着示例题已经校准。

本人可以撤回成绩，复核人员可以拒绝待审记录或撤回已批准记录。撤回、过期或目录适用范围变化时，当前计划的成绩和差距清空，状态改为需复核，未完成任务需重新确认。历史快照保留但失效成绩不能重新生成报告，查看历史报告显示失效提示。审核变动以服务端最新状态为准，重复提交请求不会恢复旧审核状态。

成绩、证明定位和审核说明保存在学生所属资源中；管理员队列仅保留索引。删除个人资料同时清除成绩和索引，以及包含成绩的历史规划、报告、个人幂等响应。管理审核的幂等响应只含记录 ID 与状态，不保留证明或分数。无正文的操作审计保留用于追踪，已经下载的历史文件不能远程撤销。
