# 账号安全与治理

2026-11-11。本地验证只用隔离测试账号和模拟发布资料，不操作用户账号注销或真实资料发布。

## 账号安全

学生及管理员可在“账号安全”校验当前密码后修改密码。修改后旋转当前会话，撤销其他设备全部会话和旧恢复码。登录、改密、恢复与注销在写入前重新检查账号状态，避免异步密码计算期间账号变更造成旧身份复活。

账号恢复采用用户主动预先生成的一次性恢复码：32 字节随机值，只显示一次，服务器只保存 SHA-256 与一年有效期。生成新码使旧码失效；恢复操作原子消费该码、重置密码并撤销目标账号全部会话。恢复不会清空当前浏览器的游客记录；之后登录继续要求原有游客迁移选择。未预留或遗失恢复码不能自动找回；邮件身份验证和真实邮件投递仍未配置，界面不伪造发送成功。恢复码不写入审计、幂等回放、浏览器存储或 URL。

普通用户注销必须重新输入当前密码并明确确认范围。在线个人记录和账号删除，全部会话/恢复码撤销；保留无内容的主体代次和操作审计，防止在途请求恢复数据。之后重新注册同名账号使用新身份。管理员需先交接权限，不支持自行注销。已下载文件不受影响；隔离恢复工具必须继续应用可信当前状态，不能恢复已注销账号及其个人数据。

## 资料治理

注销及删除个人资料成功后，同步清理本人正在运行的研究和模型/网页/聊天缓存；错误密码、错误删除范围或过期版本不会触发清理，其他用户不受影响。即使旧异步任务迟到，删除代次仍阻止结果回写。

复核员可在纠错队列写处理说明、变更状态，提交携带版本标记，过期修改被拒绝。学生在院校页面“我的纠错处理记录”查看进度和说明。处理纠错不自动修改招生事实或绕过独立审核。

发布员可查看发布记录并明确确认整次发布的撤回范围及原因；已撤回和部分撤回状态持久保存。撤回不覆写旧报告，原有资料失效门禁继续生效。审计员可读取最近 200 条执行人、动作、对象与时间；权限由服务端检查，不只依赖按钮隐藏。

已有后端仍支持指定项目修订的部分撤回；页面整次撤回必须先展示范围并再次确认。真实审核、发布和撤回由有权人员执行，自动化测试不会代签。
