# 院校专业研究的需求规则与证据链

本说明对应 `profile-research-v7`。联网报告先从画像建立调查范围、读取具体项目，再用固定规则排序。模型负责补充检索线索与解释，不能靠一句“一级推荐”改变项目层级，也不能靠漏写一所学校将已经读到的项目隐藏。

## 候选发现与事实核验

- 当前兴趣、目标和本科课程背景通过产品词表连接到全国学科目录；相关学硕、专硕同步调查。明确排除与跨专业意愿参与调查范围，但不替代学校报考条件。
- 每个意向城市都有招生单位清单检索。杭州另有小型官方发现线索表，包含杭电等学校；它只提供网址，不能证明专业招生、校区、学费或考试科目，也不是完整院校库。
- 读取学校官网正文及其同校 HTML 目录、PDF、XLS/XLSX 附件。附件必须保留父页、真实链接与同校归属，不能把父页文字伪装成附件原文。解析有进程、时间、大小和内容上限，不执行工作簿公式或宏。
- 官网编码项目会进入独立候选清单，即使模型没有提出这所学校，也会按同一规则比较。当前停招或明确年度资格冲突优先于历史资料；资格未查全不会标成已通过。
- 学校名称、招生办地址不直接证明专业培养城市。多校区安排需要专业代码对应学院、目标年度学院校区政策、各可能校区的官方地址组成证据链；可能校区跨城市或缺失地址时保持未知。校区地理链接从任何已读取学校官网发现，预置网址仅补充线索；未预置城市和学校也走同一流程。

初期最多18次搜索，全部阶段合计最多24次；官网正文合计最多24次。初期普通目录每校最多4次读取，意向城市恢复最多借用4次读取槽位，同校目录与正文附件最多12个新链接、最多3层发现。当前已读编码项目和校区政策仍缺城市时，另允许最多2次校区地理补读、每候选校最多1次；随后费用补读与前述阶段共用24次读取和每校6次上限。成功公开资料复用15分钟；失败不缓存。

## 分层与同校比较

`demand-match-v1` 分别记录城市、预算、兴趣、课程背景、培养路线和时间／测评的匹配状态及缺口。当前兴趣与目标的方向关联、培养路线及已核验城市决定是否优先比较：

- 与明确方向关联、无明确兴趣或培养路线冲突，且意向城市已核验的项目进入优先比较；未限定城市时不要求城市匹配。
- 有方向或课程关联，但城市未知／不符、兴趣或培养路线仍有差异的项目进入适合备选。
- 尚未形成明确需求关联的项目保留为探索选择。

同层先比较已核验城市，再比较匹配项数量，最后按学校与专业身份稳定排序。预算未知或较高不会独自淘汰项目；年度、学习方式或计费口径不一致的费用不强行比较。每校一个主建议，同校其他专业与学硕／专硕路线保留对照，不重复计算学校数量。规则不计算录取概率、能力门槛或虚假匹配百分比。

候选核验记录会说明哪些学校已进入比较、哪些尚缺正文或项目证据、哪些遇到明确冲突。“资料未覆盖”与“不适合”是不同状态。目标5–10校是研究覆盖目标；不足5校保留已有建议，达到数量也不掩盖意向城市覆盖缺口。

## 测评与考试、学位选择

报告使用已提交的测评快照，保存题库版本、题目修订、知识点、范围和审校状态，选取各科相应范围最近可用的记录。正式诊断与示例练习分别呈现；当前20道开发示例题、每科5题，未经过学科审校和能力标定，不能将正确率换算考研分数或断言“适合数二／不适合数一”。

测评结果用于指出已观察知识点、错误和缺失范围，生成专项诊断及复习任务。它不直接改变学校层级。数一／数二／数三和英一／英二分别比较，只有具体学校目标年度专业条目中读到的初试科目才作为当前要求；不同方向／考试组冲突时保持待确认。自命题科目只从明确初试槽位抽取，不能从参考课程或复试科目借用。

学硕／专硕比较根据明确培养偏好、科研／读博或行业实践等目标提供路线依据，并提示核对培养方案。学位类型不能代替考试要求；专业学位也可能考数学一、英语一。完整选择需要把具体项目科目、当前观察、尚未测到的范围、复习投入与培养目标放在一起比较，不能让一次小测自动做最终决定。

## 更新与检查

改变画像或测评后重新生成结论与研究报告。旧报告保留原快照，并提示重新生成新规则。来源会随招生年度与官网内容变化，固定规则保证相同画像和相同事实的排序一致，不保证不同日期的外部资料完全相同。

回归验证覆盖模型遗漏／失败后的候选恢复、HTML 到工作簿的证据归属、停招与资格冲突、同校学位路线保留、真实科目绑定、校区证据链、示例测评边界、页面显示及 Markdown 导出。真实院校烟测使用公开官网资料，不调用收费模型或搜索服务。
