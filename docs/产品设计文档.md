# 考研专业与院校推荐网站｜产品设计文档（简版）

版本：V0.1 · 日期：2026-09-22 · 状态：需求设计

## 1. 产品方向

面向准备考研、尚未明确专业和院校的中国大学生，结合个人情况、基础测评、招生数据、就业方向和院校评价，帮助学生选择适合的专业与院校，并形成可执行的备考目标。

产品重点回答：**适合学什么、值得报哪里、需要考多少、目前差在哪里、毕业后可以做什么。**

## 2. 核心用户流程

**填写个人情况与偏好 → 初步匹配专业方向 → 基础测评与答题诊断 → 推荐院校专业 → 对比、收藏并确定目标 → 查看分数与阶段任务。**

允许学生填写“不确定”、中途保存及修改条件，个人资料按需收集并支持删除。已有明确目标的学生可直接查看匹配分析；跳过测评时，明确标记能力评估依据不足。

## 3. 主要功能

| 模块 | 主要内容 |
| --- | --- |
| 学生画像 | 本科院校与专业、毕业及报考年份、相关课程基础、英语经历、备考进度、可投入时间、预算、城市及跨专业意愿。 |
| 用户偏好 | 设置就业、发展前景、政策支持、专业兴趣、学校与城市、招生透明度、风险接受程度的重要性；可主动屏蔽或恢复学校、专业。 |
| 基础测评 | 按数学、英语及首版覆盖的专业基础分层出题，结合答案、用时、简要过程和补测，识别知识薄弱点与疑似错误原因。 |
| 专业推荐 | 说明专业学习内容、适配理由、跨专业成本、相关岗位、就业门槛及需要补充的能力。 |
| 院校推荐 | 在满足报考要求的项目中，推荐最多十个“学校＋学院＋专业/方向＋学位类型＋学习方式＋招生年份”组合，展示匹配理由和主要风险。 |
| 分数规划 | 展示可获得的近三至五年招生与成绩数据，区分历史门槛、建议备考目标、当前能力及差距，同时考虑总分、单科和复试要求。 |
| 院校评价 | 汇总本科背景相关反馈、招生透明度、复试过程及培养体验；展示证据、适用范围、年份和处理进展。 |
| 对比与报告 | 并排比较候选项目，收藏或排除方案；修改条件后重新推荐，生成可保存的择校与备考报告。 |
| 管理后台 | 维护招生资料、题库及评分标准、就业与政策依据、评价证据；支持人工复核、纠错和更新。 |

## 4. 核心推荐原则

- **先满足条件，再比较适配度。** 依据目标年份的官方要求筛选；考试科目由目标招生项目确定，不能仅凭测评自由选择“数一英一”或“数二英二”。专业课准备成本也要纳入判断。
- **测评用于诊断，逐步校准。** 不能只凭答案判断“粗心”，也不能凭少量题断言考试成绩或个人能力上限。证据不足时补测或标记待评估。
- **就业、前景、政策支持分别判断。** 结合目标城市、应届硕士岗位、具体项目培养与就业情况，以及预计毕业时间分析；政策支持不等于就业保证。就业与升学分别统计，不用全校数据替代具体硕士专业表现；依据注明年份、来源和缺失情况。
- **推荐可解释、可调整。** 可按“冲刺、匹配、相对稳妥”展示；不足十个不凑数，不将分组表述为录取保证。候选清单用于比较并收敛报考目标。
- **分数口径保持一致。** 区分统考、推免及专项等不同人群；考试科目或培养项目变化时提示不可直接比较。历史最低录取分不作为安全线，不提供未经验证的精确录取概率。
- **院校评价基于证据。** 按学院、专业和年份记录，区分官方事实、经核实的经历与待核实线索，不给整校永久贴标签。单条匿名传闻不影响排序；多份独立且相互印证的反馈经复核后可提醒或降权；严重问题得到可靠确认且仍相关时，可默认移出推荐前十并展示原因。
- **缺失不等于结论。** 没有负面评价不代表绝对公平；普通本科录取少或复试权重大不能直接证明歧视。用户可查看依据、调整偏好，后台可更新整改情况或撤销失效标签。

## 5. 数据与大模型分工

| 组成 | 职责 |
| --- | --- |
| 可信数据 | 官方招生章程、专业目录、复试细则及公开成绩；可核实的就业资料、政策文件与考生反馈。保留来源、年份、更新时间，评价材料去重并脱敏。 |
| 规则与计算 | 报考资格筛选、客观题判分、历史数据统计、分数方案检查，以及按照用户偏好进行项目排序。 |
| 大模型 API | 理解学生描述、辅助分析解题过程、解释推荐依据、整理报告和回答追问；基于提供的资料工作，不能编造学校事实、就业数据或录取概率。 |
| 人工复核 | 审核题目和评分标准、争议评价及严重风险标签，处理纠错。模型不可用时，基础查询与筛选仍可使用。 |

## 6. 首版 MVP 范围

建议先面向准备全日制考研的理工科本科生，选择一至两个专业方向及一批资料可核实的院校；具体专业与院校名单在进入开发前确定。

首版完成“建档—测评—推荐—分数规划—风险提醒—对比收藏”的完整流程，包含政策、前景和就业偏好，以及必要的数据维护后台。

后续再扩展全学科覆盖、持续复测与招生变化提醒、详细周计划、复杂手写判卷、作文与复试辅导。

## 7. 首版验收方向

- 学生能够理解推荐原因、就业方向、主要风险及下一步准备任务。
- 推荐符合已知报考条件，关键事实有来源，缺失或过期信息明确展示。
- 相同输入和数据版本下，筛选与排序稳定；修改偏好后，能够解释结果变化。
- 判题与评分标准一致，分数方案同时检查单科和总分，能力不足或证据不足时如实说明。
- 评价风险分级有依据，重复转载不重复计数，用户可以查看排除原因并反馈纠错。
