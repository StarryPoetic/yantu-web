# 考研专业与院校推荐网站｜产品设计文档（简版）

版本：V0.2 · 日期：2026-09-23 · 状态：需求设计

## 1. 产品方向

面向准备考研、尚未明确专业和院校的中国大学生，结合个人情况、公共课基础、兴趣与就业目标，首先帮助学生判断和选择适合的专业，并给出学硕或专硕方向建议，再匹配院校项目、形成备考目标。**帮助尚未确定专业的学生完成专业选择，是产品的核心 MVP。**

产品重点回答：**适合学什么、值得报哪里、需要考多少、目前差在哪里、毕业后可以做什么。**

## 2. 核心用户流程

**填写个人情况与偏好 → 公共课测评与诊断 → 专业推荐与选择（含学硕/专硕建议） → 院校项目匹配 → 对比、收藏并确定目标 → 查看分数与阶段任务。**

可选分支：**专业已确定 → 专业课测评 → 更新能力差距、院校匹配与备考目标。** 专业课测评不作为进入专业推荐的前置条件；学生更换专业后，应按新方向重新判断原测评是否适用。

允许学生填写“不确定”、中途保存及修改条件，个人资料按需收集并支持删除。已有明确目标的学生可直接查看匹配分析；跳过测评时，明确标记能力评估依据不足。

## 3. 主要功能

| 模块 | 主要内容 |
| --- | --- |
| 学生画像 | 本科院校与专业、毕业及报考年份、相关课程基础、英语经历、备考进度、可投入时间、预算、城市及跨专业意愿。 |
| 用户偏好 | 设置就业、发展前景、政策支持、专业兴趣、学校与城市、招生透明度、风险接受程度的重要性；可主动屏蔽或恢复学校、专业。 |
| 公共课测评 | 专业未确定时，仅按数学、英语、政治等公共课分模块开展初测；结合答案、用时、简要过程和补测识别薄弱点，按学生情况选择模块，不强制所有人参加数学测评。政治测评用于了解备考基础，不作为专业适配的硬性排除依据。 |
| 专业推荐与选择（核心 MVP） | 无需预先填好目标专业，结合兴趣、已学课程、公共课诊断、职业目标和投入条件，给出可比较的专业方向；说明学习内容、适配理由、跨专业成本、相关岗位和需要补充的能力，帮助学生作出选择。 |
| 学硕/专硕建议与解释 | 结合科研或职业目标、培养需求、时间和预算给出建议，允许学生比较和调整；在学硕/专硕选项旁设置“学硕和专硕有什么区别？”小型说明按钮，点击或触摸后展示培养侧重点、课程与实践、常见毕业去向及报考差异，具体学制、学费和考试要求以项目为准。 |
| 专业课测评（专业确定后可选） | 在学生确认专业后，按所选专业及候选项目的考查内容按需开展，用于补充院校适配和分数规划；可以跳过，不阻断择校流程。 |
| 院校推荐 | 在满足报考要求的项目中，推荐最多十个“学校＋学院＋专业/方向＋学位类型＋学习方式＋招生年份”组合，展示匹配理由和主要风险。 |
| 分数规划 | 展示可获得的近三至五年招生与成绩数据，区分历史门槛、建议备考目标、当前能力及差距，同时考虑总分、单科和复试要求。 |
| 院校评价 | 汇总本科背景相关反馈、招生透明度、复试过程及培养体验；展示证据、适用范围、年份和处理进展。 |
| 对比与报告 | 并排比较候选项目，收藏或排除方案；修改条件后重新推荐，生成可保存的择校与备考报告。 |
| 管理后台 | 维护招生资料、题库及评分标准、就业与政策依据、评价证据；支持人工复核、纠错和更新。 |

## 4. 核心推荐原则

- **以专业选择为核心，逐步匹配院校。** 先结合个人情况与公共课基础比较专业方向，再依据目标年份报考条件匹配具体项目；专业准备成本纳入分析，但不要求先完成专业技能测试。
- **科目评估服务于院校匹配。** 数一/数二、英一/英二相关能力与学习成本评估，用于判断学生对不同院校专业考试要求的适应程度，解释可考虑的项目及差距；考试科目由目标招生项目确定，不能自由组合，也不能把学硕固定等同于数一英一、专硕固定等同于数二英二。
- **测评用于诊断，逐步校准。** 不能只凭答案判断“粗心”，也不能凭少量题断言考试成绩或个人能力上限。证据不足时补测或标记待评估。
- **就业、前景、政策支持分别判断。** 结合目标城市、应届硕士岗位、具体项目培养与就业情况，以及预计毕业时间分析；政策支持不等于就业保证。就业与升学分别统计，不用全校数据替代具体硕士专业表现；依据注明年份、来源和缺失情况。
- **推荐可解释、可调整。** 可按“冲刺、匹配、相对稳妥”展示；不足十个不凑数，不将分组表述为录取保证。候选清单用于比较并收敛报考目标。
- **分数口径保持一致。** 区分统考、推免及专项等不同人群；考试科目或培养项目变化时提示不可直接比较。历史最低录取分不作为安全线，不提供未经验证的精确录取概率。
- **院校评价基于证据。** 按学院、专业和年份记录，区分官方事实、经核实的经历与待核实线索，不给整校永久贴标签。单条匿名传闻不影响排序；多份独立且相互印证的反馈经复核后可提醒或降权；严重问题得到可靠确认且仍相关时，可默认移出推荐前十并展示原因。
- **缺失不等于结论。** 没有负面评价不代表绝对公平；普通本科录取少或复试权重大不能直接证明歧视。用户可查看依据、调整偏好，后台可更新整改情况或撤销失效标签。

## 5. 数据与大模型分工

| 组成 | 职责 |
| --- | --- |
| 可信数据 | 官方招生章程、专业目录、复试细则及公开成绩；可核实的就业资料、政策文件与考生反馈。保留来源、年份、更新时间，评价材料去重并脱敏。 |
| 规则与计算 | 按选专业前后分配测评模块，执行报考资格筛选、客观题判分、历史数据统计、分数方案检查，以及按照用户偏好进行项目排序。 |
| 大模型 API | 理解和补问学生需求、辅助分析解题过程、解释专业及学硕/专硕适配依据、整理报告和回答追问；基于提供的资料工作，不能编造学校事实、就业数据或录取概率。 |
| 人工复核 | 审核题目和评分标准、争议评价及严重风险标签，处理纠错。模型不可用时，基础查询与筛选仍可使用。 |

## 6. 首版 MVP 范围

建议先面向准备全日制考研的理工科本科生，覆盖少量可比较的专业方向及一批资料可核实的院校，并向用户说明覆盖范围；具体专业与院校名单在进入开发前确定。

**首版优先验证“学生尚未确定专业，也能获得有依据的专业选择建议”。** 完成“建档—公共课测评—专业选择与学硕/专硕建议—院校匹配—分数规划—风险提醒—对比收藏”的流程，包含学硕/专硕解释入口、政策与就业偏好，以及必要的数据维护后台。

专业课测评作为专业确认后的可选增强功能，不列为首版必备。后续再扩展全学科覆盖、持续复测与招生变化提醒、详细周计划、复杂手写判卷、作文与复试辅导。

## 7. 首版验收方向

- 未确定专业的学生，无需填写目标专业或完成专业课测评，即可获得可比较的专业建议并作出选择；专业课测评只在确认专业后按需提供。
- 学生能够理解专业和学硕/专硕推荐原因，通过说明按钮查看区别，并能调整选择；院校匹配显示实际考试科目及其与当前能力的差距。
- 学生能够理解就业方向、主要风险及下一步准备任务。
- 推荐符合已知报考条件，关键事实有来源，缺失或过期信息明确展示。
- 相同输入和数据版本下，筛选与排序稳定；修改偏好后，能够解释结果变化。
- 判题与评分标准一致，分数方案同时检查单科和总分，能力不足或证据不足时如实说明。
- 评价风险分级有依据，重复转载不重复计数，用户可以查看排除原因并反馈纠错。
