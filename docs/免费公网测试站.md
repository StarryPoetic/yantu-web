## 免费与保存限制

Render Free 闲置 15 分钟后休眠，下一次访问启动约需一分钟。SQLite 数据在休眠、重启和重新部署后会丢失，账号也可能需要重新注册。请用测试信息，不要把它作为长期保存学习资料的站点。

只创建 `Free` Web Service，不绑定支付方式、不添加付费磁盘、数据库或其他服务。无支付方式时，用完免费流量会暂停服务，用完构建额度会暂停新构建；不升级套餐。不要用定时请求刻意绕过休眠。限制以 [Render 免费方案](https://render.com/docs/free) 为准。

## 部署配置

使用仓库根目录 `render.yaml`，或在平台创建以下等价配置：

| 配置 | 值 |
| --- | --- |
| GitHub | `StarryPoetic/yantu-web`，只授权该仓库 |
| 分支 | `main` |
| 类型 / 套餐 | Node Web Service / Free |
| 区域 | Singapore（如免费实例可用） |
| Node | `24.14.1` |
| 构建 | `npm ci --include=dev && npm run build` |
| 启动 | `node scripts/render-preview.ts` |
| 健康检查 | `/api/v1/health` |
| 自动部署 | 关闭，验证提交后手动发布 |

启动入口只读取 Render 提供的非秘密 `RENDER_EXTERNAL_URL`，使用它确定 HTTPS 同源地址，监听 `0.0.0.0` 与平台 `PORT`。数据库固定在系统临时目录的 `yantu-render-preview/preview.sqlite`，与本地数据库无关。入口启用明确的测试模式，保留生产 HTTPS 与 Secure Cookie 校验，强制关闭模型/搜索、管理员初始化及代理 IP 信任。

不上传 `.env`、本地数据库、账号、日志和密钥，不创建预设管理员，也不迁移本地会话。不要在平台填写模型或搜索密钥。Render 使用动态反代时，本方案保持严格的转发 IP 策略，注册/登录可能共享代理 IP 限额（默认每 15 分钟注册 10 次、登录 40 次），遇到频控应等待，不能随意信任来访者的转发头。

1. 相关后端测试、生产构建和测试环境提示的浏览器测试通过后，创建独立 commit。

3. 公网 HTTPS 首页及 `/api/v1/health` 返回成功；登录前后均可见免费测试/数据清除声明。
4. 使用新建测试账号完成注册、画像保存、示例练习；确认报告服务显示未启用，不能发起付费调用。
5. 核对部署提交、实际地址和当前限制。休眠后数据重置是该测试方案的已知边界，不宣称持久化验收通过。

需要保存数据、持续运行后台研究任务和启用真实模型时，应另行部署具有持久盘的生产实例，完成题库/规则/目录的人工门禁，并单独确认服务预算；不能把本测试站直接宣称为完整生产服务。
