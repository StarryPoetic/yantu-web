## 3. 不能因扩展而破坏的约束

1. 专业与院校联合推荐属于核心 MVP；不要求先确定二者，也不要求完成测评。专业课仅在显式确认目标专业后可选。
2. 招生项目以完整年度组合识别；目标年份资格未知的项目不能进入已核验推荐前十，数量不足不补齐。
3. 公共课数学、英语、政治可选；初测每科五题，默认十五题。补测另建尝试；五题结果不能转换为考研分数或录取概率。
4. 客观判分、正式资格和年度榜单排序由确定性规则负责；独立研究模型可根据完整画像规划方向及比较校专业，必须引用实际取得的资料，不改变业务资格或补造事实。考试范围由项目当年资料决定。
5. 已提交测评、推荐运行和报告保留生成时版本；更新生成新版本，删除个人资料时按删除规则处理个人快照。
6. 凭据仅在服务端受控保存；文档、前端、日志、题库及模型提示词不保存实际密钥或账户标识。
