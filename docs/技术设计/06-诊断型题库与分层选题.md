# 诊断型题库建设与分层选题要求

版本：V0.1 · 日期：2026-09-27 · 状态：技术设计补充，尚未实施

## 1. 本轮范围

本轮把“题目更丰富、更有特点、能定位学生具体问题”的要求纳入设计。后续题库拟在后台保存完整题目、标准答案、解析和审核记录，再由规则选题、判分，由 DeepSeek 辅助解释。当前前端的二十道固定示例题保持原样；本文的题量、数据字段、组卷和补测均是待评审方案，不表示已经建库、出题或修改测评流程。

产品 V0.5 每科初测五题、默认三科共十五题、数学可取消的基线保持不变。扩容的是可供选择的题库；不会因为题库变大就自动增加一次初测的题数。五题只能提供有限筛查线索，未覆盖的知识点显示待评估，不推算考研得分或录取概率。

## 2. 题量与覆盖建议

建议按知识点覆盖和审核质量逐批建设，下列数量是便于估算工作的初步目标，须结合覆盖范围与审校资源确认。

| 范围 | 建议首批目标 | 覆盖重点 |
| --- | --- | --- |
| 数学 | 120题 | 极限与连续、导数与微分、积分、线性代数、概率等；具体题目须标适用考试范围。 |
| 英语 | 60题 | 词义与语境、句子结构、指代、逻辑关系、阅读推断；区分词汇障碍与理解障碍的线索。 |
| 政治 | 60题 | 概念辨析、材料理解、论据与结论匹配；需注明教材或考纲依据及适用年份。 |
| 专业课 | 另预留40题 | 专业确认后可选，按实际支持的方向建库，不作为首版上线门槛。 |

公共题库建议合计240题，专业题另计；这不是已完成数量。不能靠同一道题反复替换数字凑题数。每个重点知识点应有概念题、常规应用题和可验证错误假设的对照题；在基础、中等、较难三档中按实际需要分布，题量不足的组合明确显示覆盖不足。

## 3. 题目的诊断特点

| 设计方式 | 用途 | 解释限制 |
| --- | --- | --- |
| 成组对照 | 保持知识点相同，只改变一个关键条件，例如链式法则中的内层函数、积分区间或概率条件。 | 比较两题表现帮助提出假设，不能单凭一组题断言掌握程度。 |
| 有依据的干扰项 | 每个错误选项对应可解释的常见步骤错误、条件遗漏或概念混淆。 | 选到该项只是线索，也可能是猜测、误读或其他原因。 |
| 概念与计算分开 | 同一知识点既测概念识别，也测计算或应用，避免只统计最终对错。 | 必须有足够覆盖才能区分原因，不能把计算错误直接称为“粗心”。 |
| 情境与变式 | 用不同表述、材料或轻微变式检查学生能否迁移已学方法。 | 不靠故意歧义、超纲条件或语言陷阱制造难度。 |
| 简要过程与补问 | 鼓励填写关键一步；必要时追问使用了哪个条件或公式。 | 过程为可选输入，没有过程就明确证据不足。 |
| 自信度与用时辅助 | 可选“确定/不确定”，结合多题记录安排复查。 | 不作为独立能力结论，不因一次用时长推断能力差或不认真。 |

数学重点区分“极限替换条件、链式法则遗漏、定积分符号与面积、矩阵概念、概率独立与互斥、条件概率”等错误假设。英语重点区分词义、句法、指代和逻辑证据；政治测评只评价所测知识与材料理解，不推断个人政治认同、价值观，也不作为专业适配的硬性排除条件。

## 4. 题库数据要求

每道题拟保存稳定 ID、题库版本、科目、考试范围、知识点、前置知识、题型、难度标签及校准状态、题干/选项、标准答案、逐步解析、错误选项依据、对照题组 ID、建议补问/补测标签、原创或授权来源、适用年份和审校记录。图片与公式资源保留引用及版本。

数一/数二等是考试范围，不能当成简单的难度档位。尚未选定目标专业/项目时，优先使用共同基础题；选定后按具体项目科目核对适用范围，不由学硕/专硕类型推导。初始难度可由审校人员标注为“人工初分”，有足量且有代表性的作答数据后再校准，不能宣称初始标签已经具有测量效度。

标准答案和解析保存于后台，提交前不下发到浏览器；模型辅助接口同样不得泄露未提交题或别人的答案。发布题库采用不可变版本，答案修正产生新版本并标记受影响结果，禁止静默覆盖旧测评依据。

## 5. 分层组卷与补测

1. **选择范围**：按学生勾选的模块、目标项目适用范围和题库审核状态取候选题；只读已发布题库。
2. **初始分层**：数学基础自评用于选择起始难度配比，基础薄弱者以基础题为主，基础较好者增加综合题；保留共同基础检查。自报水平不是已证实的能力。
3. **固定初测**：每科五题满足预设知识点覆盖、不重复、考试范围适用等约束；创建尝试时固定题目、题目顺序、题库版本和组卷策略版本。刷新、返回修改和慢接口响应都不能替换已经开始的题集。
4. **规则判分**：对错、未答和提交状态分别记录；仅主动提交后生成结果。客观判分使用该次题库标准答案，模型不得改变评分标准。
5. **给出有限诊断**：展示观察到的答题证据、可能原因、尚不能区分的原因及建议下一步；不将所有知识点压成一个看似精确的能力分。
6. **自愿补测**：如以后启用，针对少量待验证假设另开一轮短测评，明确题数、范围与目的；单独保存尝试并关联原初测，不强制补测、不阻断择校。具体补测题量与入口需产品评审后另行开发。

每次重新测评可在同知识点、同难度、同审核标准的题池内换题，并记录选题依据；随机选题需保存结果和随机种子，便于回放。题库不足时优先说明缺口并缩小诊断范围，不实时调用模型生成未经审核的新题充数。

## 6. DeepSeek 的职责

组卷、权限校验和客观判分用规则完成。模型可读取已提交题目的审核解析及授权作答过程，辅助生成讲解、错误原因假设、需要追问的问题和补测标签。后台根据合法标签查询题库；模型不直接修改题库，也不执行任意数据库查询。

诊断结果应包含“所依据的题目与作答、目前观察、可能原因、证据不足之处、建议补测或复习内容”。对同一学生不能仅因模型文案变化而改变客观分数；模型无法稳定解释时返回固定解析。Flash 任务路由、成本和密钥要求见[07-DeepSeek接入与密钥管理](07-DeepSeek接入与密钥管理.md)。

## 7. 审校与质量验收要求

题库后续建设按“草拟或授权导入 → 答案和解析复核 → 干扰项与范围检查 → 小规模试用 → 标注校准状态 → 发布”推进。模型草拟的题目与人工题同样审校；优先建设少量覆盖完整、依据清楚的题组，再扩数量。

- 每道客观题答案唯一，题干条件完整，选项无重复或逻辑歧义；答案、解析和错误选项依据一致，公式与单位正确。
- 对照题确实只改变计划中的关键条件，不能额外引入未经标注的知识点而误诊。
- 明确正确、错误、未答、猜测、步骤与选项冲突、范围不适用及知识点未覆盖时的反馈；诊断样例保留人工审核结论。
- 单科五题组卷规则、数学可跳过、末题主动提交、题集版本隔离和初测/补测分开均需验收。
- 专业更换后重判专业课题集适用性；政治基础不会触发专业硬排除；五题结果不会转成总分预测或录取概率。
- 建立独立的模型验证题与作答轨迹，不把待验证答案放进同一生成任务；检查解释引用是否真实、错误原因是否过度推断、是否泄露未提交题及失败时能否回到固定解析。

## 8. 实施前待确认

需确认首批知识点清单、题量目标、原创/授权题源、学科审校人员、难度校准方案、是否启用自愿补测、补测题量和模型任务预算。上述决定写入设计后，再按用户后续指令开展具体出题、建库和开发；本轮仅整理这些要求。
