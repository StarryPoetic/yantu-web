# 联合推荐、测评与分数规划设计

> 实施状态（2026-09-27）：本版同步完整画像驱动的具体学校与专业研究建议，区分适合度建议与目标年度资格核验。实际已实现能力、配置及上线验收边界见[实施说明](../实施说明.md)；未完成的内容建设与运营门槛不视为已交付。

版本：V0.5 · 状态：实施同步 · [文档索引](00-文档清单与需求映射.md)

## 1. 输入、输出与责任边界

推荐以完整年度招生项目为结果单位，关联专业方向供双向探索。用户可先看专业、先看院校或都未确定；未测评不阻断推荐。输入固定为画像、选择、目标年度、显式筛选、目录与规则版本，以及可为空的 `assessmentRefs[]`。字段和实体以 [02](02-数据模型与可信数据.md)为准。

正式年度项目推荐输出为最多十个已核验可报考项目、待核验候选、未入选原因、各维度依据和运行版本。相同输入和版本得到相同资格、分值及顺序；模型不能改变此计算。独立联网研究另生成有据的校专业适合建议，年度资格未知不等于不适合，不能因此移除全部建议。Demo 的匹配值、梯度和模拟分数不能作为生产规则。模型不可用时仍返回基础规则解释。

## 2. 推荐流水线

专业探索结论先独立运行：读取完整全国目录 → 当前已保存画像 → 适用的已提交公共课诊断 → 明确兴趣/本科基础/学习目标的可解释关联 → 输出结论与补问。未确定专业也能生成结论，不将排序后的第一个类别自动确认为目标；没有背景或兴趣证据时保留全目录探索，不默认计算机。政治或少量数学题不构成排除某专业的资格依据。

专业结论的关联理由不等于招生资格或精确适合度，rank与fitScore保持null，资格按具体院校年度项目核验。示例、未提交、已撤回或不适用的诊断不进入正式能力依据，并展示排除原因。结论页自动使用本人已提交公共课记录，重测与画像更新后重新生成快照。

全国目录代码通过学位一致的对应函数关联项目，`filters.disciplineCodes`、确认专业、屏蔽与计划复核使用同一匹配规则。某类别无已收录招生项目时清楚显示空覆盖，不回退到计算机项目。

旧专业结论解释接口只整理固定结论中的依据ID，服务端验证并渲染已有理由。独立研究先以全国184条基础目录和完整画像规划方向，再用真实搜索及学校官网生成具体校专业建议；研究方向不受旧结论少量高亮类别或本科专业单项锁定。输入包括兴趣、职业目标、城市、预算、跨专业意愿、学位偏好、七项优先级、时间、课程、备考情况、补充说明和适用诊断，尊重明确拒绝及未知项。模型失败不冒充完成画像分析；基础规则结论、待补问题和下一步仍可用。

以下流水线针对已收录的年度招生项目：

1. **规范输入**：区分未填、不确定和具体值。显式确认的专业、学校、学位筛选和屏蔽属于本次用户约束；城市偏好、培养建议和权重属于可调整偏好。界面须明确筛选与偏好的区别。未匹配的自定义城市只保存偏好文本，不猜测城市或资格。
2. **固定依赖**：解析画像和选择版本，读取一个已发布目录、兼容规则及适用诊断。输入版本过期或已删除时拒绝计算，不自动替换成当前版本。显式请求重新计算才创建新运行。
3. **逐项核验资格**：针对项目目标年度官方条件，得到 `eligible/ineligible/unknown` 与证据。任何明确不符合条件使结果为 `ineligible`；没有不符合但有必要条件未知则为 `unknown`；全部必要条件核实符合才为 `eligible`。未知进入待核验列表，不占前十；本科院校层次或普通本科录取少本身不能判不符合。
4. **应用用户约束和去重**：学校/专业/项目屏蔽按范围展开，允许恢复；确认专业或学校后在该范围重算，并提供解除约束入口。一个项目关联多个专业标签时只出现一次，不挤占多个名额；不同学院、方向、学位或年度仍是不同项目。
5. **计算分维度依据**：专业侧考虑兴趣、课程、职业目标、跨专业准备成本与培养取向；项目侧考虑城市、资源、实际科目、预算、透明度与审核风险。就业机会、发展前景、政策支持分别使用对应证据，缺失为未知，不默认为零或利好。
6. **风险处理与稳定排序**：先执行已复核严重风险的移出规则，再对可推荐候选进行排序；有限降权只来自满足 02 证据要求的案例，匿名传闻不参与。平分按稳定 `programId` 排序。输出证据覆盖和贡献明细，不用无依据的匹配百分比。
7. **返回解释**：显示专业与项目理由、实际科目、准备成本、风险、来源、年份和缺失项。数量不足不补齐；无合格项目显示空结果及具体阻塞条件。历史预览与当年可报考候选分开展示。

待核验列表说明缺失条件和核验入口，不能按位置暗示已可报考。拒绝的项目按权限提供理由，不在公共响应中暴露其他用户信息或受限证据原件。

## 3. 排序规则包与评审门槛

七项用户设置沿用产品原文：就业、发展前景、政策支持、专业兴趣、学校与城市、招生透明度、风险接受程度。它们不能直接被当作含义相同的七个加分项；尤其风险接受程度用于选择风险策略，不能反向增加高风险项目分数。预算、投入时间和跨专业意愿属于画像条件，不冒充新增偏好维度。

| 规则包必须定义的内容 | 检查要求 |
| --- | --- |
| 输入到维度的映射、量纲与方向 | 哪些是权重、硬约束或风险策略；每项只计算一次，避免相关指标重复加分。 |
| 权重边界和标准化 | 拒绝负值、非有限数和越界值；合法权重和为零时采用明确公布的中性配置或要求重设，不除以零。 |
| 缺失维度处理 | 明确最低证据要求及是否重分配权重；不得因缺少不利数据而系统性获益；不足时标记暂不能排序或待核验。 |
| 风险与分组 | 证据等级、有限降权、严重风险排除、整改撤销与适用期；冲刺/匹配/相对稳妥的条件独立定义。 |
| 诊断使用 | 知识点证据如何影响准备成本；政治不作为专业硬排除；未覆盖知识点不当作不会。 |
| 回放样例和兼容范围 | 规则包能复算历史样例，声明所需目录结构与诊断版本；由业务及技术复核。 |

具体映射、权重及分组阈值仍受 [08 的 D-04](08-变更与扩展约定.md)阻塞。在完成规则评审前不能发布生产排序或以默认数字代替。资料不足时可只提供事实检索和待核验列表，界面须说明尚无有效推荐结果。“冲刺／匹配／相对稳妥”是有依据的定性比较，不是录取概率或保证。

每次运行保存候选数量、排除阶段及原因、维度状态与贡献、实际使用的版本。两次运行差异区分用户输入、目录、诊断和规则变化；同时变化时分别列出，不将资料修订归因于学生能力。旧运行标记需刷新，不能改写。

## 4. 学位建议与测评引用

学硕/专硕建议依据科研或职业目标、希望的课程/实践方式、时间、预算和具体项目培养事实，输出倾向及理由或证据不足。建议可覆写，不自动排除另一类型；考试科目、学制和费用按当年项目核实，不从学位类型推导。两个说明入口的交互规范见 04。

题库、组卷、五题初测、状态机和诊断限制统一见 [06](06-诊断型题库与分层选题.md)。推荐读取公共课、专业课和补测的独立引用，并逐项校验主体归属、已提交状态、范围与版本适用性；同一知识点的重复测量不得重复计权。初测和补测冲突时保留矛盾证据，不默认为后者全覆盖前者。

专业变更后重算专业课适用性，不删除或改写旧测评；不适用结果列在未采用依据中并说明原因。公共课是否适用仍按范围判断，不能因为专业切换一概丢弃。五题筛查、自报基础或单次用时不能转换为分数、录取概率或人格标签；未测和未覆盖保持待评估。

## 5. 分数规划

确定目标和编辑计划是独立动作。项目详情或规划页选择项目后，通过 [04 的目标接口](04-接口与前端交互.md)立即保存 `targetProgramId` 和明确匹配的确认专业，再进入规划；界面从选择记录恢复学校、专业、年度和学位。尚未填写目标分数也能保存目标。选择失败保留原页和原目标，不显示成功提示。取消目标保留确认专业及历史计划，但界面显示尚未选择目标。

| 展示对象 | 来源及限制 |
| --- | --- |
| 历史门槛 | 近三至五年可获得的官方或已审核记录，显示年份、人群、考试科目、环节、满分、指标和样本；缺年留空，不插值。 |
| 建议备考目标 | 固定目标项目修订和规则，在可比资料下提供可调整目标与理由；资料不足显示待制定或待核验。用户可保存自行设定目标，但须注明尚未经资料验证。 |
| 当前能力及差距 | 使用有来源和日期、科目/满分/口径一致的可靠模考或足量测量；否则只给知识点诊断，分数差距待评估。 |

规划先核验目标年度所有适用的总分、单科及复试条件，再检查分科目标的满分范围与合计。未满足已核验门槛必须提示并拒绝保存为有效规划，可保留编辑草稿；条件未知时保存带待核验标记的计划，不宣称满足。历史最低录取分不是安全线，跨人群或科目口径的数据不用于硬校验。

可比时逐科显示“目标 − 当前表现”及依据；已达到目标显示达到，不将负差值表述成需要倒退。历史科目、满分或复试计分变化时分组或断开趋势。目标项目或科目变更产生新计划版本；数据更新提示重算，不自动覆盖用户自定目标。建议目标与阶段任务的具体映射受 D-06 评审约束。

更换或取消目标使原计划转 `needs_review`、`valid=false` 并保留版本历史，未完成任务标记需重新确认。规划页只将与当前 `targetProgramId` 相同的计划装入编辑区；其他项目计划只保留历史，不沿用其分数和任务。相同完整目标或计划重复保存不产生额外版本与任务。确认专业与旧计划不兼容时，旧版本也不能作为新报告的当前方案，已有历史报告仍可查阅。

## 6. 任务、对比与报告

任务来源包括已确认目标的实际科目、薄弱知识点、资料核验和阶段规划。任务完成状态独立保存，不因推荐重排重置。目标或科目变化时，旧任务保留关联；受影响的未完成任务标记需重新确认，再建立新版本任务，避免重复生成或误沿用旧科目任务。新确认专业与既有目标不兼容时，计划标记 `needs_review` 并要求重新确认目标，不静默清除历史或把旧计划继续当作有效依据。未测评时提供一般性核验和备考任务，不编造个性化差距。

对比按完整项目并列城市、学位、培养、科目、资格、费用、历史口径、就业/政策证据与风险；缺失显式显示，不可比项不给优劣结论。报告固化指定推荐运行和计划版本，说明来源、时间、缺失、风险和能力限制。之后发布新资料只附过期提示；刷新报告生成新 ID。

联网研究报告是基础专业结论之后由用户触发的增强：固定当前结论和选择中的目标，方向规划后检索学校证据，再输出具体学校与具体专业。规划与报告使用当前 `profileEvidence` 字段引用，由服务端绑定值，模型不必复写整段画像；显式提供的旧值仍拒绝。已清空备注、不确定项和默认50优先级不进入可用依据。每项建议至少以两个不同真实画像字段解释匹配理由，并列出取舍和准备要求，不能只重复本科专业或泛泛称“适合”。学校及专业关联必须有实际学校官网支持；明确示例、停招或没有该关联证据的建议拒绝。它不修改确定性资格、年度榜单排序、确认专业、分数计划或正式招生知识库，也不能把五题诊断写成真实录取依据。

适合度与年度核验独立：历史或年份不明的真实官网可支撑条件性建议，`admissionStatus` 标为 `needs_verification`；目标年度相关证据充分才标 `current_evidence`，仍不代表用户符合全部资格。历史学费、名额、分数及资格不能改写成本年事实。仅搜索摘要或缺乏校专业官网关联为 `partial`；无真实来源或配置未就绪为 `blocked`。`completed` 表示本次有界适合建议流程已完成，可以同时含年度待核验的建议，不表示全国覆盖、正式资格已核实或录取保证。

停招或限制必须绑定到当前具体专业，不把相邻专业的条件套用到当前建议；归属不清时保持待核验，明确全校停招仍排除。目标年度官方限制与实际用户背景存在明确冲突时剔除该建议；历史限制只作待核验风险，不能冒充当年禁止条件。没有具体费用依据时不得断言学校超预算或负担得起，应提示核验学费与生活成本。核心学校身份、具体硕士专业、引用及综合理由必须通过；局部无据条目可移除，但之后仍须至少两个有效且不同的真实画像维度和至少一项有效取舍，否则整项建议剔除。不得为保留数量降低证据要求。不合格卡片或总述不清空其他合格建议，报告标为partial并说明删减。院系名和具体考试代码仍按该卡引用及适用年度核验。

`failureStage` 可选值为 `preparing/researching/analyzing/writing`，表示失败发生的真实阶段；阶段失败、模型输出校验失败和用户信息不足分别解释。已保存画像充分但模型格式错误时，不提示用户必须先选学校或重新填写画像；只有实际画像不足或有效规划中的明确追问才请求补充。

研究任务的阶段持久化、刷新恢复、引用检查和费用边界分别由 [04](04-接口与前端交互.md)、[05](05-安全运维与验证.md)及 [07](07-DeepSeek接入与密钥管理.md)定义。

## 7. 验收引用

规则发布至少覆盖：未定专业且跳过测评、同校多项目、学位与常见科目组合不同、已知不符与未知条件并存、重复专业标签、屏蔽恢复、零权重/缺失维度、匿名转载去重、诊断冲突和专业变更、五题全对但能力仍不能换算分数。对应 [05](05-安全运维与验证.md) 的 T-01～T-04、T-07；独立目标与研究增强另见 T-20、T-21、T-22。具体数值样例须随 D-04/D-06 的评审规则补齐。
