## 1. 权限与个人信息边界

账号密码使用Node scrypt及独立随机盐，恒定时间比较；原始密码不得进入日志、业务幂等表、模型或API响应。用户名统一规范，密码验证受账户与来源双层频控，哈希计算有并发上限。登录/注册旋转Cookie与CSRF，退出撤销会话；跨设备使用同一账号主体。匿名接口仅保留旧记录兼容，新界面默认要求登录。

管理员初始化使用服务端 `YANTU_BOOTSTRAP_ADMINS`，只首次创建，不自动更改既有账号密码或把学生提升为管理员。录入/复核/发布/审计权限仍独立，注册输入role被拒绝。初始配置凭据必须通过受保护环境传入，禁止写入Git；已建账号只保存哈希。



主体归属统一使用 02 的 `subjectId`，由服务端会话取得；所有本人资源包括草稿、诊断、推荐、报告、缓存和作业都核验归属。知道资源 ID 不代表有权限。注册登录和账号绑定按 D-03 实施；姓名不是使用前提，只有注册时显式选择才可认领当前游客主体，已有账号登录不合并游客记录。

| 角色 | 允许操作 | 边界 |
| --- | --- | --- |
| 学生/游客 | 读取公开资料及本人记录，保存、提交、导出和删除获准个人数据 | 不能读未发布资料、未提交标准答案或他人作答。 |
| 资料录入 | 维护授权范围内的草稿、来源及纠错材料 | 不能把自己录入的内容直接作为已审核事实。 |
| 学科/资料复核 | 核验答案、口径、来源和争议材料 | 常规资料至少一名独立复核；规则包及风险案例至少两人复核，录入者不能单独批准。 |
| 发布人员 | 发布已满足审核及验证门槛的版本，紧急撤回 | 不能跳过复核或修改已发布内容。 |
| 运维/审计 | 运行维护和最少必要的审计访问 | 不因运维身份默认获取完整画像、答案或证据原件；敏感访问另授权并留痕。 |

学生页面与管理入口分开。HTTPS、受保护的 HttpOnly/Secure/SameSite 会话 Cookie、写操作 CSRF 防护、输入校验和速率限制属于正式接入要求。文件附件限制类型和大小，校验真实格式，隔离原件与公开脱敏副本；下载必须鉴权，短期链接不能代替访问控制。上传 HTML、Markdown 或模型文本呈现时过滤危险内容，外部材料不作为指令执行。

推荐只采集必要字段，模型只发送完成当前任务所需的最少数据。解题过程分析由用户主动触发，告知发送范围；具体传输、保留和预算先解决 D-08，未解决时使用固定解析。模型专属配置、密钥轮换建议和输出检查统一见 [07](07-DeepSeek接入与密钥管理.md)。

## 2. 删除语义与并发保护

正式“删除个人资料”至少覆盖画像及历史版本、城市偏好、测评草稿/作答/诊断、个人推荐快照、个人报告副本以及可识别的计算/解释缓存。不能仅删当前画像而让旧报告恢复其内容。收藏、排除、确认专业、目标计划/任务、纠错材料及必要审计的保留或删除范围由 D-03 决定，并在删除前明确展示；未定前不得上线含糊的“全部删除”。

若某类记录允许保留，必须去除被删除画像、作答、诊断及其推导摘要，不能以保留目标或审计为由保留完整个人历史。保留目标可只含经确认的项目引用；计划中的个性化推导需删除或重新生成。公共招生事实和真正无法关联个人的汇总不随个人删除；假名化记录仍按可关联个人资料管理。

删除设计流程：

1. 检查主体和已展示的删除范围版本，原子写入删除作业，递增 `deletionGeneration` 并将该代个人数据标记为不可服务；接口返回 202 和完成查询入口。
2. 立即禁止旧代次读取或写入受删数据，失效报告下载和个人缓存。后台生成作业、队列消息及在途请求在提交结果前重新检查代次，不能把资料写回。
3. 各模块按幂等作业清理数据库、文件、缓存和索引中的范围内数据；部分失败保持删除中并重试，不误报完成。浏览器清理对应草稿/缓存，并拒绝较早请求回填。
4. 在线范围完成后标记完成并说明备份清理安排；完成后才允许创建新代画像。主体可继续查询删除状态及获准保留记录，不以保留会话绕过数据禁读。
5. 备份按已批准期限到期清除；恢复前先重放删除标记和撤回清单，再开放服务，防止已删个人数据或已撤回事实复活。第三方模型的留存与删除能力须在启用前核实并如实说明。

D-03 决定具体保留范围与期限，D-10 决定删除处理和备份清理时限。本轮不承诺即时物理删除、自动删除用户已下载文件或清除聊天平台记录。删除审计仅保留必要的事件、状态及范围证明，不复制原个人内容；其关联标识和到期策略也需明确。

## 3. 发布、后台作业与运行

开发、测试和生产分离数据、密钥及权限；模拟夹具仅供开发和测试。部署划分为前端静态资源、业务 API/作业、数据库和受控文件存储。版本兼容、迁移和回滚遵循 [08](08-变更与扩展约定.md)，资料审核状态遵循 [02](02-数据模型与可信数据.md)。

生成报告、发布资料和删除操作通过持久化 `Job` 执行，状态为 queued/running/succeeded/failed，记录类型、主体或管理归属、幂等键、固定输入引用和有限重试信息。事务内同时写业务状态与待执行记录；可先用数据库作业表，只有实际需要时再引入队列及事务消息表。执行器按租约领取、失败回收，重复执行不能重复发布或生成额外业务记录。

当前联网研究使用单独的持久化 `ResearchJob`，状态与字段见 [02](02-数据模型与可信数据.md)。网络和模型工作在数据库事务外执行，每次真实阶段与终态写入账号记录。当前执行器在进程内运行；刷新读取原任务，服务重启将遗留在途任务标记中断失败，不自动恢复上游调用、不自动付费重试。用户显式重新生成才创建后续任务。配置缺失在调用前生成 blocked 记录，仍可查阅规则结论；只有搜索摘要或原文覆盖不足的结果为 partial。该实现不承诺分布式队列或无人值守断点续跑。

联网材料是不可信输入，检索/官网读取执行 HTTPS、主机范围、地址与重定向限制、超时和长度限制，不访问本机及私网。输出只允许本次证据中的引用和全国目录代码，原文事实、适合建议与年度资格分开；来源不能自动进入正式知识库。完整画像先送服务端模型规划方向，再以公开专业和目标词检索；姓名不发送模型，本科院校只作用户自述背景，完整画像和原始补充不原样进入搜索词；仅提取公开专业、城市偏好、年度与可选目标学校。两次研究模型调用默认 Pro/high，由服务端选择，与常规咨询共享 ModelRuntime 额度及并发账本，不能以切换阶段绕过预算。准确配置、计费与密钥约束见 [07](07-DeepSeek接入与密钥管理.md)。

作业执行时重新校验权限、删除代次、输入引用与撤回状态；丧失权限或依据无效时失败，不读取最新版本替代固定输入。业务提交与评分在一次事务内完成，不等待模型；模型讲解是后续可失败的增强。目录指针切换必须原子化，缓存带版本；紧急撤回还要更新有效性屏障，使旧缓存不能绕过撤回。

日志只存请求/作业 ID、版本、状态、耗时和必要计量；不记录完整画像、作答原文、认证头、未脱敏证据或原始供应商错误。发布与管理审计只追加，受独立权限保护；个人记录删除后的审计遵循上一节。监控包括 API 错误率、延迟、空推荐/待核验比例、资料临期、审核积压、模型降级与费用、作业失败、删除停滞。

## 4. 故障与降级矩阵

| 失败场景 | 对用户的行为 | 恢复与限制 |
| --- | --- | --- |
| 模型失败、超额或输出核验失败 | 返回固定解析和规则解释，基础测评与推荐可用 | 按 07 有界重试，不自动升级高价模型。 |
| 题池不足或范围无覆盖 | 指明不足，可调整模块或跳过测评 | 不减题、不重复凑题、不用实时生成补齐。 |
| 资格关键字段缺失、过期或冲突 | 待核验；不进入已核验推荐前十 | 人工修订发布后新建推荐运行。 |
| 采集或资料源不可用 | 使用仍有效的最后发布快照并显示日期 | 过期关键事实暂停使用；不以最后发布为由无限续用。 |
| 规则未发布或兼容检查失败 | 公开检索可用，推荐明确未就绪 | 503，无临时默认分数替代。 |
| API/数据库不可用 | 保留已加载内容及本地草稿，提示重试 | 不声称可继续服务端计算；不启用 Demo 冒充真实结果。 |
| 报告/发布作业失败 | 展示作业状态和重试入口 | 固定输入重试；输入撤回/删除时必须重新发起有效任务。 |
| 联网研究缺配置、仅摘要或服务中断 | 分别显示 blocked、partial 或失败说明，保留可读历史与已取得资料 | 刷新只恢复任务；中断不自动付费重试，显式重试先核验当前依据和预算。 |
| 删除或缓存清理部分失败 | 保持数据禁读，显示处理状态 | 重试并告警，禁止新任务重建被删内容。 |

备份覆盖业务库、来源原件和版本清单，恢复演练检查引用完整、权限、删除标记和撤回状态。性能、可用性、容量、恢复点/恢复时间及人工复核时限由 D-10 定稿，不能以未设指标宣称达标。
