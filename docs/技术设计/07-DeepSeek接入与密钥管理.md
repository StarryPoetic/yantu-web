# DeepSeek 接入、模型路由与密钥管理

版本：V0.1 · 日期：2026-09-27 · 状态：设计草案与连通性验证记录

## 1. 需求决定与实施边界

按本轮用户要求，首选 DeepSeek，优先使用质量满足任务要求且成本较低的 Flash 模型。题库、审核后的标准答案、确定性判分与选题规则拟由业务系统保存和执行；模型拟用于诊断解释、补问、题目草拟及报告整理。根据用户后续明确的边界，本轮只补充技术文档，不实施题库扩充、配置变更或模型业务接入。前述连通性检查已完成，但不保留探测脚本、不保存真实凭据，网页仍未连接 DeepSeek。

截至本次核验，官方将 **DeepSeek-V4.1-Flash** 对应的 API 模型 ID 标为 **`deepseek-flash`**，基础地址为 `https://api.deepseek.com`。服务端配置保存这个 API ID，不能把展示名直接当请求参数；后续别名指向可能改变，发布前要重新核对模型列表及回归样例。[官方首次调用说明](https://api-docs.deepseek.com/zh-cn/)、[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

## 2. 模型任务路由

| 任务 | 默认处理 | 模型输入与限制 |
| --- | --- | --- |
| 按科目、范围、知识点和难度选题 | 数据库查询与组卷规则，不调用模型 | 固定本次题集、答案版本和组卷规则；不足时返回覆盖不足，不临时生成题补齐。 |
| 客观题判分、未答统计 | 服务端标准答案与规则，不调用模型 | 不接受客户端或模型上传的“最终分数”；数学表达式判等另做规则设计。 |
| 已提交错题讲解、测评总结、推荐理由改写 | `deepseek-flash`，显式关闭思考模式 | 仅传该次任务需要的已审核依据和学生授权的作答；短输出，不传整个题库或完整画像。 |
| 分析多步解题过程、审核复杂数学草稿 | `deepseek-flash`，必要时开启思考模式并采用当前支持的较低推理档位 | 先在独立验证集比较效果与成本；模型意见是错误原因假设或审核线索，不能自动改标准答案。 |
| 批量题目草拟与标签建议 | Flash，后台离线批次、限量生成 | 结果进入草稿区，经过答案唯一性、公式、解析和干扰项审核后才能发布。 |
| Flash 无法可靠完成的复杂任务 | 固定解释、人工复核或明确“证据不足” | 更高价模型需单独评审质量收益和预算后启用；不因重试失败自动切到 Pro。 |

模型服务接收题目、学生作答和审核解析，返回结构化的 `evidence_question_ids`、`possible_errors`、`uncertainty`、`followup_tags` 与解释文本。服务端核验引用题目确属于该用户已提交尝试、标签属于允许集合、解释未改变正确答案后才展示。未提交题的答案和其他用户记录不能通过模型接口获取。单条错误选项不足以断言“粗心”；缺少过程时应补问或标记无法区分原因。

需要模型辅助查询时，可提供受限工具，如“按允许的知识点标签取候选题”，由后台执行数据库查询，再把授权范围内的结果返回模型；不允许模型执行任意 SQL、任意网络 URL 或直接发布题目。[官方工具调用说明](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)

## 3. 成本和响应控制

Flash 是当前首选，最终性价比通过题目审核正确率、诊断证据一致性、响应时延与每任务费用共同评估。不能仅凭模型名称认定适合所有数学任务。

本次官方价格快照：Flash 每百万输入 token（未命中缓存）空闲/高峰为 1/2 元，每百万输出 token 为 4/8 元；实际费用受缓存、思考输出、时段及后续调价影响。价格仅作 2026-09-27 预算参考，运行时以官方计费与用量为准，不向用户承诺固定单次费用。[官方价格表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

建议首版普通解释控制在约 5,000 输入 token 内、最多 800 输出 token、30 秒超时；复杂草稿审核使用独立任务预算。这些为待压测的初始配置，不能使用模型最大上下文和最大输出作为默认额度。记录模型 ID、提示词版本、任务类型、token 数、时延、结果状态及费用估算，不记录凭据或完整个人输入。

每用户和全站分别设置日额度与并发限制；同一次尝试、同一题及同一提示词版本的重复点击可复用已校验结果，缓存按用户和版本隔离。输入数据或模型别名版本改变后重新验证。只对明确可重试的限流/服务错误做有上限的退避；超时后是否已计费未知，不能无限重试。额度不足或模型超时返回已有标准解析和规则结论，测评提交、判分及基础推荐继续可用。

## 4. 密钥与账号信息

- 真实 API 密钥和账户 ID 不写入文档、代码、测试数据、版本记录或报告；本文件只记录配置项名称。官方调用使用 Bearer API 密钥，用户提供的账户 ID 不作为模型 ID，也不需要写进请求正文。
- 正式密钥由后端从部署平台密钥管理或受保护的服务环境读取，配置名建议为 `DEEPSEEK_API_KEY`。禁止使用 `VITE_` 等会打包到浏览器的变量前缀；禁止把密钥放入网页、浏览器存储、URL 或客户端请求体。
- 后续本地调试优先使用系统密钥管理或无回显输入。实施时须让仓库忽略 `.env` 和 `.env.*`，示例文件只能含占位符；本轮没有修改忽略配置。忽略规则不能清除已经提交过的秘密。开发、测试和正式环境使用独立凭据。
- 网络请求限定到官方 HTTPS 主机，不接受前端指定服务地址；禁止把认证头转发给重定向目标。模型提示词、第三方资料和搜索请求不包含密钥。
- 日志、错误页面和测试输出不显示密钥、部分密钥字符、认证头、环境变量清单或原始上游错误。记录固定错误类型与状态码即可，响应内容也按允许字段过滤。
- 本轮密钥曾由用户直接贴入聊天。项目文件扫描无法清除聊天或平台保留记录，不能承诺已经从所有位置消失；建议在控制台轮换该密钥。新的密钥通过受保护配置提供，不再贴入聊天；本轮不自动撤销或更改用户账号。

## 5. 本次连通性验证

| 检查 | 2026-09-27 结果 | 能证明什么 |
| --- | --- | --- |
| 官方 `GET /models` | HTTP 200，包含 `deepseek-flash` | 当前凭据可访问模型列表，首选别名可见。 |
| 官方 `POST /chat/completions` | HTTP 200，指定 `deepseek-flash`，非思考模式 | 当前凭据可完成该模型的一次实际短调用。 |
| 首次合成 JSON 检查 | 输入 63、输出 9、合计 72 token | 基本请求/响应可用，不证明数学能力或诊断质量。 |
| 增强复核 | 返回模型标识为指定 Flash、结束原因为 stop、无思考内容；未给出答案的简单数学请求输出校验通过，输入 67、输出 9、合计 76 token | 指定路由与响应完整性通过；两次生成共148 token，仍不代表完整题库质量验收。 |

探测只发送人工构造的短输入，未发送学生资料、账户 ID 或题库原件；凭据经无回显标准输入送入进程，不写入项目配置、命令行参数或探测结果。进程结束后不持久化凭据。成功记录不保证未来余额、网络、限额和模型别名不变，也不代表网站已接入。

后续实施时，连通性检查应通过约定的服务端密钥配置或安全输入通道执行，没有安全输入通道就停止；不得自动尝试其他凭据。成功需同时核验 HTTP 状态、首选模型、完整结束、思考模式和结构化内容。普通测试应模拟响应，不访问网络或产生 API 费用；真实探测只在明确授权后进行。本轮探测脚本已撤回，仅保留不含凭据的事实记录。

## 6. 上线前验证

1. **鉴权与失败路径**：错误密钥、额度不足、限流、超时、模型不可用和重定向均不输出认证内容；不能在失败后悄悄升级高价模型。
2. **模型质量**：固定一组不混入生成提示词的验证题与作答轨迹，覆盖答对、答错、未答、猜测、步骤与选项冲突、信息不足及诱导泄题；由人工确认标准结论，比较 Flash 不同模式的证据一致性。
3. **题目安全**：草稿不能直接进入正式题库，已提交结果的解释与当次题库版本一致；未提交题不提供解法泄露通道。
4. **隐私与成本**：扫描仓库和前端构建产物；验证日志脱敏、用户数据隔离、删除及缓存清除、额度/超时/重复请求控制。
5. **决策落地**：D-08 的供应商选择更新为 DeepSeek 优先；具体日预算、复杂任务升级条件、数据保留与传输范围仍需确定。有效密钥通过受保护配置部署后，再做环境验收。

配套题库建设要求见[诊断型题库与分层选题](06-诊断型题库与分层选题.md)。具体出题、开发和上线在用户后续明确要求实施时再开展。
