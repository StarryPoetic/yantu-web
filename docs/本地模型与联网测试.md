# 本地模型与联网测试

更新日期：2026-09-27。适用于研途 V0.5。模型和搜索由本地后端调用，**不需要先把网站部署到公网**。其他人长期访问时再配置服务器、域名、HTTPS 与持久化数据库。

## 1. 创建博查搜索密钥

本项目已改用博查（Bocha）作为默认联网搜索服务，DeepSeek 继续负责分析和回答。无需继续办理 Brave 的海外银行卡绑定。需要的是 **Web Search API**；不用另外购买 AI Search 来替代已有的 DeepSeek。

1. 打开 [博查登录页](https://open.bochaai.com/login)，支持中国大陆 `+86` 手机号验证码和微信登录；未注册手机号按页面提示自动注册。
2. 登录后查看首页“购买资源包 → 免费试用”。官方[免费资源说明](https://bocha-ai.feishu.cn/wiki/RWdvw557Li3IJekGeLkcDFa3n1f)列出每个用户可领取一个 1,000 次资源包；该活动页面更新时间为2025-09-19，是否仍可领取以当前账户为准。若成功领取，可先用它测试；不能将一次性试用包当作每月赠送或长期免费。
3. 在控制台的 API KEY 管理中创建密钥，名称可填 `yantu-local-test`，复制并保存。若界面要求先开通服务，选择 Web Search API。
4. 将密钥写入项目根目录 `.env` 的 `BOCHA_API_KEY`，不要写入代码、文档或公开仓库。

每份研究报告包含两个模型阶段：规划使用同一研究模型（默认Pro）非思考模式，4096输出token/30秒；最终使用Pro/high分析具体学校与专业，默认12000输出token/120秒（输出最高16384，含思考）。每阶段结构、引用或画像校验失败时最多修复一次，全部调用共享日额度；传输、认证、预算、超时和取消不自动重试。最多六次搜索、六次官网正文读取和十二项来源，因此搜索次数不等于报告份数。没有可用额度时，需要按控制台当前价格购买额度后才能真实联网；DeepSeek费用另算。不会自动向另一家搜索供应商重试产生费用。

来源：[博查官方接口说明](https://bocha-ai.feishu.cn/wiki/RXEOw02rFiwzGSkd9mUcqoeAnNK)、[官方接入项目与密钥说明](https://github.com/BochaAI/bocha-search-mcp)、[官方服务条款与赠送额度说明](https://open.bochaai.com/terms-of-service)。

## 2. 填写本地配置

已有 `.env` 时直接编辑对应行，不要覆盖已有 DeepSeek 密钥；没有时复制 [.env.example](../.env.example) 为 `.env`。

```dotenv
YANTU_MODEL_ENABLED=true
DEEPSEEK_API_KEY=填写自己的DeepSeek密钥
YANTU_SEARCH_ENABLED=true
YANTU_SEARCH_PROVIDER=bocha
BOCHA_API_KEY=填写自己的博查密钥
YANTU_RESEARCH_MODEL=deepseek-v4-pro
YANTU_RESEARCH_EFFORT=high
YANTU_RESEARCH_TIMEOUT_MS=120000
YANTU_RESEARCH_MAX_OUTPUT_TOKENS=12000
YANTU_MODEL_USER_DAILY_TOKENS=60000
```

只把示例值换成自己的密钥。DeepSeek 控制台的账户 ID 不用于本项目鉴权。不要增加 `VITE_` 前缀；这会使秘密暴露给浏览器。`.env` 已被 Git 忽略。博查密钥不能填进 `DEEPSEEK_API_KEY` 或 `BRAVE_SEARCH_API_KEY`；每家供应商使用自己的字段。

保存配置后停止原服务并重新执行 `npm run dev`，打开 `http://127.0.0.1:4173/`。修改 `.env` 不会自动重新加载正在运行的后端。正式启动 `npm start` 同样会读取 `.env`；系统环境变量优先于文件。

默认 `YANTU_DNS_MODE=system` 使用系统 DNS。如果本机代理将公网域名解析成 `198.18.*` 等虚拟地址，网页访问保护会拒绝请求；本机测试遇到了这一情况。可以显式设置 `YANTU_DNS_MODE=public-doh`，由固定的阿里云 HTTPS DNS 服务解析公网地址。该模式仅发送目标主机名，不发送画像、搜索内容或密钥；仍校验全部地址、固定连接 IP、验证 TLS 主机并禁止重定向，不允许内网或代理虚拟地址绕过检查。DNS 服务不可用时返回失败，不自动回退到其他解析方式。

## 3. 验证流程

1. 注册或登录学生账号，完成并保存个人画像，填写实际兴趣或暂时留空，不必选择计算机。
2. 可完成公共课测评，查看专业探索结论；也可跳过，报告说明能力证据不足。示例题只能体验流程，不能证明真实水平。填写兴趣、职业目标、城市预算、跨专业与学位偏好、优先级和时间，避免只有本科专业一项背景。
3. 在结论中的联网研究区域查看服务状态，点击生成报告。准备资料、检索官网、模型分析、整理结果分别来自后端任务；刷新页面可恢复进度。
4. 优先检查具体学校＋具体专业、至少两个真实画像维度的匹配理由、取舍和逐项年度状态；研究范围与来源可展开。历史官网能支持条件性建议时不因缺目标年度全部清空，但学费、名额和资格仍须核验。“已取得目标年度相关资料”也不等于已符合报考资格；只有搜索摘要或无校专业正文依据仍为部分结果。
5. 打开页面边角咨询球，输入自己的问题测试连续咨询；需要实时资料的问题可允许联网。正常咨询与深度报告共用服务端额度。

`GET /api/v1/research/status` 只检查配置是否齐备，不探测供应商、不消耗额度。真实密钥、余额、网络和所选模型能否使用，需要一次实际请求确认；不要把“已配置”当作“真实联网已验证”。

## 4. 常见状态

| 页面状态 | 处理方式 |
| --- | --- |
| 尚未配置网页搜索密钥 | 检查 `.env` 中 `YANTU_SEARCH_PROVIDER=bocha` 和 `BOCHA_API_KEY`，并重启后端。 |
| 网页搜索尚未启用 | 设置 `YANTU_SEARCH_ENABLED=true` 并重启。 |
| 方向规划结果格式未通过校验 | 已保存画像不必重填，也不要求先选学校；系统最多一次有界修复，仍失败时按真实阶段展示，可在服务正常后显式重新生成。 |
| 模型认证未通过 | 检查 DeepSeek 密钥是否有效、复制完整。 |
| 今日模型额度不足 | 检查用户及全局日额度；思考模型预留的输入/输出额度更高。 |
| 只有搜索摘要、官网读取失败 | 可查看部分结果及已有来源；缺校专业正文依据时不强行生成学校建议。 |
| 官网目录为PDF | 研究任务可受控提取纯文本；普通咨询默认不读取PDF。仅研究PDF下载最多5000000字节/8秒，HTML仍512000字节，解析另限5秒、80页、120000字符；扫描件不做OCR，失败时保留摘要并说明缺口。 |
| 有历史校专业官网，但目标年度待核验 | 可比较条件性适合建议和匹配理由；报考条件、学费、名额须等当年资料核实，不等于被排除或已可报考。 |
| 资料已变化、结论过期 | 先重新生成当前画像的专业探索结论，再生成研究报告。 |

本地日额度是单进程保护，重启会重置；长期运行需要持久化费用记录。博查余额独立于 DeepSeek 模型费用。自动化测试全部使用模拟供应商响应，不消耗真实账户额度。
