## 可执行顺序

1. 复核下表和机器台账原文定位，优先已有正文可补的范围/表头问题；以真实负例测试防止错年、错专业、导航页和估计值误计。
2. 国家线建立同年适用声明→学科/学位类型和A区→数值原文完整链；学科评估建立第四轮矩阵→0802→目标项目明确依托关系。链条缺一保持待补。
3. 对报录比/推免补同年同人群分子分母，对本科/跨考背景补公开群体统计，对就业保留学院/研究生口径。没有数据不估算，不以经验评价替代。
4. 审查首批8条真实项目线索、补完整身份后转换为正式导入草稿。由实际资料负责人录入、独立复核人审校、发布人发布；不代填审核身份。
5. 加入其他城市和文商理工医真实语料后做多画像回放。技术回归与真实覆盖分别验收；当前只证明这些已保存机械相关原文。
